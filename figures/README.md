# Figures

Marquee figures referenced from `cases/<group>/<name>/README.md` and
`../REPRODUCE.md`. Each is regeneratable from the case data shipped under
`../cases/<group>/<name>/` using the indicated `tools/` script.

## Slab — receding angle vs Weber number

- **`we_vs_theta.pdf`** / **`.png`** / **`.csv`**
  Reproduction of dissertation Fig. 4.11 using `cases/slab/{slab72-we1000,
  we126, we349}` (and 6 additional Weber points from the underlying sweep that
  fed into the table; the .csv carries the full numeric breakdown). Two
  simulation series shown: θ at the run final time `t_f = 1.4e-3 s` (black
  filled circles) and θ interpolated at the dissertation's `t_f = 5e-4 s`
  (blue dashed triangles). Red curve: dissertation interpolant
  `θ = 0.864 We^0.506 + 0.845`. Red squares: dissertation Fig. 4.10 raw points.
  Regenerated by `tools/we_vs_theta.py`.

## Zalesak — n-phase interface sharpening

- **`zalesak_2row.pdf`** / **`.png`** *(marquee comparison)*
  Two-row indicator strip `I = Σₖ k·αₖ` over a full revolution (eight frames,
  ω = 30 rad/s). Top row: `cases/zalesak/nosharp_donor` — donor-cell
  advection, no NPhaseIntSharp. Bottom row: `cases/zalesak/pm_muscl_g1e-3` —
  MUSCL advection + Parameswaran-Mandal interface sharpening with γ = 10⁻³.
  White dotted contours are the analytical α₀ = α₁ = 0.5 isolines under rigid
  rotation of the IC. Regenerated by `tools/render_indicator_strip.py`.

- **`zalesak_gamma_sweep_full_7row.pdf`** *(supplementary)*
  The seven-row γ sweep (NOSHARP-donor + PM+MUSCL with
  γ ∈ {0, 1e-4, 1e-3, 1e-2, 2e-2, 4e-2}) that justified picking γ = 10⁻³ as
  the mid-range representative for `pm_muscl_g1e-3`. Demonstrates monotonic
  improvement in slot preservation with increasing γ and full numerical
  stability across the entire range. Underlying runs are not shipped (they
  duplicate the sweep evidence captured in the 2-row figure plus the chosen
  cases); the PDF is provided for full provenance.

## SIDI — pure-sharpening validation

- **`sidi_pm_g4e2_thickness.pdf`**
  Per-disk characteristic interface thickness `ε_char(t) / h` extracted from
  `cases/sidi/sidi_4phase_pm_g4e2`. Each disk's diffuse band collapses from
  ε_char/h ≈ 8.5 to ε_char/h ≈ 0.14 over ~400 steps (no advection, only the
  Parameswaran-Mandal sharpening operator acting). Regenerated by
  `tools/sidi_thickness.py`.

- **`sidi_pm_g4e2_alpha_strip.pdf`**
  Alpha-field indicator strip across the same 4-phase SIDI run, with the
  three analytical disk centers and radii overlaid. Visual companion to the
  thickness convergence plot. Regenerated by `tools/render_sidi_strip.py`.
